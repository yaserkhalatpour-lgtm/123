% ========================================================= % دامنه تابع مرکب g o f(x/2) % =========================================================

\begin{tcolorbox}[ enhanced, breakable, colback=blue!4, colframe=blue!70!black, boxrule=2pt, arc=4mm, title={⭐ آموزش کامل ـ به دست آوردن دامنهٔ تابع مرکب}, fonttitle=\bfseries ]

فرض کنید نمودار دو تابع داده شده است و می‌خواهیم طول بازهٔ دامنهٔ تابع مرکب زیر را به دست آوریم:

\[ \boxed{ (g\circ f)\left(\frac{x}{2}\right) } \]

طبق صورت سؤال، دامنهٔ تابع \(g\) برابر است با:

\[ \boxed{ D_g= \left(-\frac12,+\infty\right) } \]

و نمودار تابع \(f\) یک پاره‌خط است که از نقطهٔ

\[ (-3,0) \]

شروع شده و به نقطهٔ

\[ (0,-2) \]

می‌رسد.

هدف ما پیدا کردن طول بازهٔ دامنهٔ تابع مرکب است.

\end{tcolorbox}

% ========================================================= % پیش نیاز اول % =========================================================

\begin{tcolorbox}[ enhanced, breakable, colback=yellow!6, colframe=orange!75!black, boxrule=1.8pt, arc=4mm, title={🟠 پیش‌نیاز اول ـ دامنهٔ تابع چیست؟}, fonttitle=\bfseries ]

دامنهٔ یک تابع، مجموعهٔ تمام مقادیری از \(x\) است که می‌توان آنها را به عنوان ورودی تابع قرار داد.

مثلاً اگر:

\[ f(x)=\sqrt{x} \]

باشد، چون عبارت زیر باید تعریف شده باشد:

\[ x\geq0 \]

داریم:

\[ D_f=[0,+\infty). \]

بنابراین هنگام تعیین دامنه همیشه باید بررسی کنیم که تابع برای چه ورودی‌هایی تعریف شده است.

\end{tcolorbox}

% ========================================================= % پیش نیاز دوم % =========================================================

\begin{tcolorbox}[ enhanced, breakable, colback=green!4, colframe=green!60!black, boxrule=1.8pt, arc=4mm, title={🟢 پیش‌نیاز دوم ـ دامنهٔ تابع مرکب}, fonttitle=\bfseries ]

تابع مرکب به صورت زیر تعریف می‌شود:

\[ \boxed{ (g\circ f)(x)=g(f(x)) } \]

یعنی:

\[ x \xrightarrow{\ f\ } f(x) \xrightarrow{\ g\ } g(f(x)). \]

پس ابتدا \(f\) روی \(x\) عمل می‌کند و سپس خروجی \(f\) به عنوان ورودی وارد تابع \(g\) می‌شود.

بنابراین برای اینکه:

\[ g(f(x)) \]

تعریف شده باشد، باید دو شرط داشته باشیم:

\[ x\in D_f \]

و:

\[ f(x)\in D_g. \]

پس:

\[ \boxed{ D_{g\circ f} = \{x\in D_f\mid f(x)\in D_g\} } \]

این مهم‌ترین فرمول این سؤال است.

\end{tcolorbox}

% ========================================================= % پیش نیاز سوم % =========================================================

\begin{tcolorbox}[ enhanced, breakable, colback=purple!4, colframe=purple!65!black, boxrule=2pt, arc=4mm, title={🟣 پیش‌نیاز سوم ـ خواندن دامنه از روی نمودار}, fonttitle=\bfseries ]

طبق صورت سؤال، نمودار \(f\) پاره‌خطی است که از:

\[ (-3,0) \]

تا:

\[ (0,-2) \]

ادامه دارد.

پس:

\[ x\in[-3,0]. \]

بنابراین دامنهٔ \(f\) برابر است با:

\[ \boxed{ D_f=[-3,0] } \]

از طرف دیگر، چون کوچک‌ترین مقدار \(y\) روی نمودار برابر \(-2\) و بزرگ‌ترین مقدار آن برابر \(0\) است، برد تابع نیز:

\[ \boxed{ R_f=[-2,0] } \]

است.

\end{tcolorbox}

% ========================================================= % پیش نیاز چهارم % =========================================================

\begin{tcolorbox}[ enhanced, breakable, colback=cyan!4, colframe=cyan!65!black, boxrule=1.8pt, arc=4mm, title={🔵 پیش‌نیاز چهارم ـ شرط ورود به تابع \(g\)}, fonttitle=\bfseries ]

طبق صورت سؤال:

\[ D_g= \left(-\frac12,+\infty\right). \]

این یعنی هر عددی که وارد تابع \(g\) می‌شود باید شرط زیر را داشته باشد:

\[ \boxed{ y>-\frac12 } \]

اما ورودی تابع \(g\) در تابع مرکب، خودِ \(f(x)\) است.

پس باید داشته باشیم:

\[ f(x)>-\frac12. \]

این همان شرط اصلی مسئله است.

\end{tcolorbox}

% ========================================================= % به دست آوردن معادله خط % =========================================================

\begin{tcolorbox}[ enhanced, breakable, colback=orange!4, colframe=orange!75!black, boxrule=2pt, arc=4mm, title={🟠 گام اول ـ به دست آوردن معادلهٔ خط \(f\)}, fonttitle=\bfseries ]

برای خطی که از دو نقطهٔ:

\[ (-3,0) \]

و:

\[ (0,-2) \]

عبور می‌کند، ابتدا شیب را به دست می‌آوریم:

\[ m= \frac{y_2-y_1}{x_2-x_1}. \]

پس:

\[ m= \frac{-2-0}{0-(-3)} = -\frac23. \]

معادلهٔ خط را به صورت:

\[ y=mx+b \]

می‌نویسیم.

بنابراین:

\[ f(x)=-\frac23x+b. \]

چون نقطهٔ \((0,-2)\) روی خط قرار دارد:

\[ -2=-\frac23(0)+b. \]

پس:

\[ b=-2. \]

در نتیجه:

\[ \boxed{ f(x)=-\frac23x-2 } \]

برای:

\[ -3\leq x\leq0. \]

\end{tcolorbox}

% ========================================================= % شرط دامنه مرکب % =========================================================

\begin{tcolorbox}[ enhanced, breakable, colback=red!4, colframe=red!70!black, boxrule=2pt, arc=4mm, title={🔴 گام دوم ـ اعمال شرط دامنهٔ \(g\)}, fonttitle=\bfseries ]

برای تعریف شدن:

\[ g(f(x)) \]

باید:

\[ f(x)>-\frac12. \]

از طرفی:

\[ f(x)=-\frac23x-2. \]

پس:

\[ -\frac23x-2>-\frac12. \]

عدد \(2\) را به طرف دیگر می‌بریم:

\[ -\frac23x> -\frac12+2. \]

بنابراین:

\[ -\frac23x>\frac32. \]

اکنون دو طرف را در \(-\frac32\) ضرب می‌کنیم.

چون در یک عدد منفی ضرب می‌کنیم، جهت نامساوی عوض می‌شود:

\[ x< \frac32\left(-\frac32\right). \]

پس:

\[ x<-\frac94. \]

از طرفی دامنهٔ خود \(f\):

\[ -3\leq x\leq0 \]

است.

بنابراین باید اشتراک زیر را پیدا کنیم:

\[ [-3,0] \cap \left(-\infty,-\frac94\right). \]

در نتیجه:

\[ \boxed{ D_{g\circ f} = \left[-3,-\frac94\right) } \]

است.

\end{tcolorbox}

% ========================================================= % نکته درباره باز و بسته % =========================================================

\begin{tcolorbox}[ enhanced, breakable, colback=yellow!7, colframe=orange!80!black, boxrule=2pt, arc=4mm, title={⭐ چرا \(-\frac94\) باز است ولی \(-3\) بسته است؟}, fonttitle=\bfseries ]

این قسمت از سؤال بسیار مهم است.

در نقطهٔ:

\[ x=-3 \]

داریم:

\[ f(-3)=0. \]

و چون:

\[ 0>-\frac12, \]

عدد \(0\) در دامنهٔ \(g\) قرار دارد.

پس \(x=-3\) مجاز است و بنابراین:

\[ \boxed{-3\text{ بسته است}.} \]

اما در:

\[ x=-\frac94 \]

داریم:

\[ f\left(-\frac94\right) = -\frac12. \]

ولی دامنهٔ \(g\) برابر است با:

\[ \left(-\frac12,+\infty\right) \]

و خودِ:

\[ -\frac12 \]

در دامنهٔ \(g\) نیست.

پس:

\[ \boxed{ -\frac94\text{ باز است}. } \]

بنابراین:

\[ \boxed{ D_{g\circ f} = \left[-3,-\frac94\right) } \]

\end{tcolorbox}

% ========================================================= % طول بازه % =========================================================

\begin{tcolorbox}[ enhanced, breakable, colback=blue!4, colframe=blue!70!black, boxrule=2pt, arc=4mm, title={🔷 گام سوم ـ محاسبهٔ طول بازه}, fonttitle=\bfseries ]

دامنهٔ تابع مرکب برابر است با:

\[ \left[-3,-\frac94\right). \]

برای محاسبهٔ طول بازه، اختلاف دو کران را حساب می‌کنیم:

\[ L= -\frac94-(-3). \]

چون:

\[ 3=\frac{12}{4}, \]

داریم:

\[ L= -\frac94+\frac{12}{4}. \]

پس:

\[ L= \frac{12-9}{4} \]

و:

\[ \boxed{ L=\frac34 } \]

نکته:

باز یا بسته بودن دو سر بازه، در محاسبهٔ طول بازه تأثیری ندارد.

\end{tcolorbox}

% ========================================================= % اگر g o f(x/2) منظور باشد % =========================================================

\begin{tcolorbox}[ enhanced, breakable, colback=purple!4, colframe=purple!65!black, boxrule=2pt, arc=4mm, title={🟣 اگر منظور سؤال واقعاً \((g\circ f)(x/2)\) باشد}, fonttitle=\bfseries ]

اگر عبارت سؤال دقیقاً این باشد:

\[ (g\circ f)\left(\frac{x}{2}\right), \]

ابتدا می‌دانیم:

\[ D_{g\circ f} = \left[-3,-\frac94\right). \]

اما ورودی تابع مرکب در اینجا:

\[ \frac{x}{2} \]

است.

پس باید:

\[ \frac{x}{2} \in \left[-3,-\frac94\right). \]

بنابراین:

\[ -3\leq\frac{x}{2}<-\frac94. \]

هر سه طرف را در \(2\) ضرب می‌کنیم:

\[ -6\leq x<-\frac92. \]

در نتیجه:

\[ \boxed{ D_{(g\circ f)(x/2)} = \left[-6,-\frac92\right) } \]

و طول این بازه:

\[ L= -\frac92-(-6) \]

است.

چون:

\[ 6=\frac{12}{2}, \]

داریم:

\[ L= \frac{12}{2}-\frac92 = \frac32. \]

پس اگر منظور دقیقاً \((g\circ f)(x/2)\) باشد:

\[ \boxed{ L=\frac32 } \]

است.

\end{tcolorbox}

% ========================================================= % نکته طلایی % =========================================================

\begin{tcolorbox}[ enhanced, breakable, colback=green!5, colframe=green!65!black, boxrule=2pt, arc=4mm, title={🏆 نکتهٔ طلایی امتحانی}, fonttitle=\bfseries ]

برای سؤال‌های دامنهٔ تابع مرکب همیشه این زنجیره را در ذهن داشته باشید:

\[ \boxed{ x \longrightarrow f(x) \longrightarrow g(f(x)) } \]

پس:

\[ \boxed{ f(x)\in D_g } \]

شرط اصلی است.

در این سؤال:

\[ D_g= \left(-\frac12,+\infty\right) \]

پس:

\[ f(x)>-\frac12. \]

با توجه به:

\[ f(x)=-\frac23x-2 \]

به دست آوردیم:

\[ x<-\frac94. \]

و چون:

\[ D_f=[-3,0], \]

اشتراک می‌گیریم:

\[ [-3,0] \cap \left(-\infty,-\frac94\right) = \left[-3,-\frac94\right). \]

بنابراین:

\[ \boxed{ D_{g\circ f} = \left[-3,-\frac94\right) } \]

و طول آن:

\[ \boxed{ \frac34 } \]

است.

اگر عبارت مسئله دقیقاً

\[ (g\circ f)\left(\frac{x}{2}\right) \]

باشد، دامنه به:

\[ \boxed{ \left[-6,-\frac92\right) } \]

تبدیل شده و طول آن:

\[ \boxed{ \frac32 } \]

خواهد بود.

\end{tcolorbox}
